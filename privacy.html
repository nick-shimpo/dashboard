Privacy Policy

PAI Finance — Personal finance tracking for Nicholas Goodall.

Last updated: 2 March 2026

What data is collected

This application accesses bank account data (balances and transactions) via the Enable Banking API, solely for personal use by the account holder.

How data is used

Data is stored locally on the account holder's personal infrastructure and used exclusively for personal financial tracking. No data is shared with third parties.

Data storage

All financial data is stored on a private, locally-hosted system. No data is transmitted to external servers beyond the Enable Banking API connection required to retrieve it.

Data retention

Data is retained for as long as the account holder requires it and can be deleted at any time.
